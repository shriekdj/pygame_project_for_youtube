## 🛠️ Prerequisites & Setup
This project uses [uv](https://docs.astral.sh/uv/) for incredibly fast Python package management. Make sure you have Python and `uv` installed on your system.

1. **Clone the repository:**
```bash
git clone [https://github.com/shriekdj/pygame_project_for_youtube.git](https://github.com/shriekdj/pygame_project_for_youtube.git)
cd pygame_project_for_youtube
```

2. **Create a virtual environment:**
```bash
uv venv
```

3. **Activate the environment:**
```bash
source .venv/bin/activate  # On Linux/macOS
# .venv\Scripts\activate   # On Windows
```

4. **Install Dependencies:**
```bash
uv sync
```

## 🚀 How to Run

You can run the game scripts using your activated virtual environment, or you can use uv run to execute them without needing to manually activate the environment first.
Navigate to the specific episode folder and run:

```bash
uv run main.py
```
